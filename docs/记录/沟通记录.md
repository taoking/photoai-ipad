## 2026-11-21

### 第 1 轮：范围和规则（写功能列表、开发计划 v0.2）

Claude 分析 Mac 版（`photoai-mac-v2` 1.0.0，`a291868`）后写了功能列表和开发计划 v0.1，问了清卡、签名、系统版本、导出等问题。用户答复：

> 只处理我的a7c2相机卡，清卡时没有其他引用的照片预览数据全部删掉，不需要无卷关联照片功能

> （收藏夹、星级算不算引用）不算 一起删；（开发者账号）暂时没有，提供个脚本方便重装；（系统）26.6左右 不支持27；导出存到文件夹，如果能提供存到照片app的选项更好，没有也行；另外再简化开发一些 ipad属于零时应急使用 所有插入的卡都认为是同一张 256g v60相机卡，ipad是1T；更新文档但不要开发

决定（写进交接的“用户定下的规则”）：只认一张卡；清卡清空库里所有照片和预览，收藏夹、星级不算引用；没有“无卷关联照片”；免费 Apple ID 签名 + 重装脚本；部署目标 26.0；导出到文件夹，存到“照片”App 放 P1。按用户要求只更新文档，没有写代码。

### 第 2 轮：开始 M0

- 用户：“ipad pro已连接电脑；  开始m0”。这就是交接里要的“开始 M0 之前先确认一句”。
- 实际情况和文档的出入：iPad 的系统是 **iPadOS 26.7.3**（文档写的 26.6），部署目标 26.0 不受影响；设备名“iPad (3)”，型号 iPad8,1。开始时开发者模式是关的，用户按提示打开了。
- 工程生成方式：交接写的“选哪种问用户”。这台 Mac 上已经装了 XcodeGen，Claude 直接选了 XcodeGen（`project.yml` 进仓库，`.xcodeproj` 不进，`reinstall.sh` 每次重新生成），在这一轮的回复里告诉了用户；用户想换成手建的 Xcode 工程可以再改。
- Bundle ID 定为 `com.tao.photoai.ipad.<4 位随机后缀>`（免费账号要全球唯一；具体值只在不进仓库的 `Config/Signing.xcconfig` 里）。**定下后不要改。**
- 第一次跑 `reinstall.sh`：构建失败，`No Accounts`——Xcode 里没登录 Apple ID（钥匙串里有一张 Apple Development 证书，但账户列表是空的）。请用户在 Xcode → 设置 → 账户里登录。
