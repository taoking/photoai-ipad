# 1.0 验收：发布 1.0.0

> 2026-11-22，分支 `release-1.0`（从 M4 全部合并后的 main 开出）。Mac：macOS 27.3，Xcode 27.0。设备：iPad Pro 11 英寸（2018），iPadOS 26.7.3。
> 真机上的步骤由用户做，没做的写 NOT RUN。

## 范围

开发计划 §7 最后一步：写 `功能说明.md`、打 1.0。用户：“写功能说明 打tag release 并整理一级目录文件，将开发文件，记录转移到子目录；完成相关工作，本机打包配置留在本地并有说明文档如何七天后再次快速打包”。

## 做了什么

| 项 | 内容 |
| --- | --- |
| 功能说明 | 一级目录 `功能说明.md`：先记住的规则、一次完整的流程、浏览 / 选片 / 键盘 / 导出 / 后台 / 设置 / 清卡、运行日志、不做的 |
| 重新打包 | 一级目录 `重新打包.md`：什么时候装（期内重装不续期）、三步、本机要有的东西（签名配置、证书、Apple ID、描述文件、构建缓存、工具）、出错对照表、换 Mac 时怎么找回 Bundle ID、免费账号限制 |
| README | 一级目录 `README.md`：一段话、文档链接、目录说明 |
| 整理目录 | `交接.md`、`功能列表.md`、`开发计划.md` → `docs/开发/`；文档里的相对链接、`CLAUDE.md`、开发计划 §2 的目录图跟着改 |
| 版本号 | `project.yml` 的 `MARKETING_VERSION` 0.0.1 → 1.0.0 |
| 本机打包配置 | `Config/Signing.xcconfig` 不变、仍只在本机（`.gitignore` 排除）；文档里不写它的值 |
| 发布 | tag `v1.0.0`、GitHub Release（只有说明，不附安装包：免费签名的包只能装在这台 iPad 上，里面带 Team ID 和设备信息） |
