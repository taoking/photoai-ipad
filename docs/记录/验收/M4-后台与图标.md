# M4 验收：后台继续处理、应用图标（第 6 项）

> 2026-11-22，分支 `m4-background`（从合并了第 5 项的 main 开出）。Mac：macOS 27.3，Xcode 27.0。设备：iPad Pro 11 英寸（2018），iPadOS 26.7.3。
> 核心层在 Mac 上 `swift test`；界面在 iPad Pro 11 英寸（M5）模拟器（iOS 27.0）上跑界面测试。**后台继续处理只能在真机上试**（模拟器上系统不批）。真机上的步骤由用户做，没做的写 NOT RUN。

## 范围

开发计划 §7 M4 第 6 项：后台继续处理（F-07）、应用图标（F-52）。用户：“合并后开始第 6 项”。

## 做了什么

| 功能 | 怎么做的 |
| --- | --- |
| F-07 读卡切到后台接着做 | iPadOS 26 的“继续处理任务”（`BGContinuedProcessingTask`）。导入时还要做的预览 ≥ 300 张（约 15 秒以上）、应用在前台，就申请一次；扫描中新照片进库、待做的变多时也会申请。系统批了，切到后台导入不停，系统在屏幕上显示“PhotoAI 读卡”和进度（预览 x / y 张，然后读对焦框 x / y 张），读完自己消失。后台时照样每 3 秒看卡，拔卡就停下；导入完了就不看了，不在后台新开导入 |
| | 系统没批（设备忙、关了后台刷新、张数少），或者中途收回了（时间到了、用户在系统的进度上点了停）：和以前一样停下，回到前台自动接着做。日志写“申请了继续处理任务”“继续处理任务没批：…”“继续处理任务被系统收回” |
| F-07 导出切到后台接着导（Claude 加的） | 导出 ≥ 30 张时同样申请（“PhotoAI 导出 N 张”，进度是张数和 MB）。批了就不再用以前的 `beginBackgroundTask`（它的时间一到会把导出停掉）；没批照旧 |
| 诊断：重做全部预览和对焦框 | 设置 → 诊断。卡上有文件的照片 1600 预览和对焦框改回待做，卡连着马上开始重做；缩略图、星级、选择、收藏夹不动。给真机试后台用：卡早就读完了，不用清卡就能有 2,000 多张要做 |
| F-52 应用图标 | `Scripts/make-icon.swift` 搬自 Mac 版，图样不变（深色底、两张叠着的照片、金色的星）；iPadOS 要铺满、不透明，圆角由系统裁，所以去掉 Mac 版的圆角方和外阴影，整幅放大到铺满。`Scripts/make-icon.sh` 写进 `App/Assets.xcassets`（只要一张 1024，别的尺寸系统缩） |

技术上要注意的（Apple 论坛 DTS 的说法，SDK 头文件对得上）：

- `Info.plist` 的 `BGTaskSchedulerPermittedIdentifiers` 放通配符 `<Bundle ID>.continued.*`（`Config/Info.plist`，和生成的 Info.plist 合并）。每次申请用新的标识符（加随机串），**先注册这个具体的标识符再提交**；只注册通配符系统不认。
- 只能在前台申请；`strategy = .fail`：系统不能马上跑就直接不批，不排队。
- 进度要一直在走，停住约 20 秒系统会收回。预览每张几十毫秒、对焦框每 200 张报一次（约 2 秒），导出每张报一次。
- 提交用 `submit(_:)`（27 起标了废弃，部署目标 26 不报警告）；新的 `submitTaskRequest(_:)` 27 才有，不能用。

和计划不一样、Claude 自己定的（没有问用户）：

- 导出也接上了（功能列表 F-07 原来只写了预览）：用户最在意导出稳不稳，做法一样，多十几行。
- 门槛：导入待做预览 ≥ 300 张、导出 ≥ 30 张。更少的切到后台系统给的那点时间差不多够（M3：27 张 21 秒在后台导完）；Apple 也建议 30 秒以内的活别用这个。
- 加了“重做全部预览和对焦框”诊断按钮，方便在真机上试。
- 图标没做深色、着色两种变体，交给系统自动处理。

### 真机步骤

1. 装好后看主屏幕上的图标。打开应用，插卡等读完。
2. 设置 → 诊断 → “重做全部预览和对焦框”。提示“2148 张预览开始重做”。
3. 过几秒按 Home 键（或从底部上滑）回到主屏幕。屏幕上应该出现系统的进度：“PhotoAI 读卡 · 预览 x / 2148 张”。等 1–2 分钟，期间可以用别的 App、锁屏也行。
4. 回到 PhotoAI：底部应该是一直在做或已经做完（“读卡完成”），不是“已停下：切到后台”。
5. 再按一次“重做全部预览和对焦框”，切到后台后在系统的进度上点停（如果有这个按钮），再回来：应该自动接着做。
6. 选 30 张以上照片导出到文件夹，切到后台等它导完，回来看结果。
