# M4 验收：补充（P1）

> 2026-11-22 开始，分支 `m4-extras`。Mac：macOS 27.3，Xcode 27.0。设备：iPad Pro 11 英寸（2018），iPadOS 26.7.3。
> 核心层在 Mac 上 `swift test`；界面在 iPad Pro 11 英寸（M5）模拟器（iOS 27.0）上用 1 万张合成库跑界面测试；真机上的步骤由用户做，日志用 `Scripts/pull-log.sh` 拷回 Mac 核对。开发计划 §7 的 M4 按顺序做、可以随时停，这一段做了第 1–4 项。**真机步骤还没做，下面真机部分都是 NOT RUN（#20 安装除外）。**

## 范围

- M3 验收留下的：中途拔卡时停下前把几十个文件记成“失败”（M3 验收 #25）。用户：“好的 改一下”。
- 第 1 项：收藏夹（F-25）；导出范围加收藏夹（F-30）；清卡检查的“选过但没导出”算上收藏夹（F-40）。
- 第 2 项：外接键盘快捷键（F-26）。
- 第 3 项：导出星级文件、从文件导入星级（F-34、F-51）。
- 第 4 项：存到“照片”App（F-33）。
- 第 5、6 项（单张换原图、直方图、对焦框；后台继续处理、应用图标）没做。

### 真机步骤

插上卡，打开应用（覆盖安装，库还在）。

1. **收藏夹**：侧栏“新建收藏夹”，起个名字。点“选择”选几张，工具栏“收藏夹”（叠起来的方框）→“加入「名字」”。侧栏点这个收藏夹看是不是这几张；选一张 →“收藏夹”→“移出”，再点撤销。单张视图里底下一排的收藏夹按钮：轻点是加入上一次的收藏夹，按住出菜单。侧栏里按住收藏夹可以改名、删除（删除不删照片）。
2. **收藏夹导出**：侧栏点收藏夹，点工具栏“导出”，看范围是不是“收藏夹名 N 张”（不用真的导）。
3. **键盘**（有键盘的话）：单张视图里按 `1`–`5`、`0`、`P` / `X` / `U`、`←` `→`、`Z`（100% ↔ 适合屏幕）、`B`（加入上一次的收藏夹）、`Esc` 或 `⌘.` 回网格；网格里选几张按数字打星，按空格打开第一张。按住 `⌘` 看快捷键列表。**重点看两件事**：从单张视图回到网格后，网格里的键还灵不灵；单张视图里点了星星按钮后，`⌘Z` 还灵不灵。不灵的话告诉我是哪一步。
4. **导出中途拔卡**：选 30 张左右导出到文件夹，导到一半拔卡，看结果页是不是只说“卡没连接了”，没有一长串失败。插回去再导一次。
5. **星级文件**：设置 → “星级文件” → “导出星级文件…” 存到“文件”里；把它导回来：“从文件导入星级…” 选刚存的文件，看确认页（星级会变的应该是 0 张）。有 Mac 版写的星级文件也可以试一个。
6. **存到“照片”**：选 5–10 张有 RAW + JPEG 的，导出 →“导出到”选“照片”App，文件选“RAW + JPEG”，开始。第一次会问权限。导完到“照片”App 里看：一张照片、带 RAW 标记。
7. **清卡检查**（不用清）：设置 → 清卡…，看“选过但没导出”有没有算上只在收藏夹里的。
8. 告诉我做完了，我用 `Scripts/pull-log.sh` 拉日志填表。

## 和计划不一样的地方

- “上一次的收藏夹”：本次运行里最后用过的；刚打开应用时取库里最近加过照片（或最近新建）的那个。Mac 版只记在内存里。
- 删收藏夹时和它有关的撤销记录去掉，重做记录整个清掉（系统的 `UndoManager` 没法凭空登记重做）。
- 侧栏的收藏夹一节放在“全部照片”下面、日期上面：日期多的时候不用往下翻。
- 选择模式下“完成”“全选”在左边，“已选 N 张”在标题下面（侧栏开着时右边放不下）。
- F-26 空格在网格里打开第一张选中的，没选就是屏幕上第一张（Mac 版网格有焦点格，iPad 版没有）。
- 存到“照片”先复制到临时文件夹（用导出那套：流式、卡拔了停下），存进“照片”后删掉；存好了才记“导出过”。“照片”里认不出存过的，同一张再存会多一份，中断后“再导一次”只导这次没存成的。
- 星级文件用 `.md`，每行“文件名  星级”，没有标题行（Mac 版读的时候标题行会算成“忽略的行”）。

第 1–4 项代码完成：核心层 75 个测试全过，模拟器界面测试 13 个过（见 #10）。外接键盘在模拟器上只能测一部分（`Esc` 送不到、送键偶尔丢），键盘相关的放到真机上验（#23）。真机步骤等用户做。
