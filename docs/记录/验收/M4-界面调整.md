# M4 验收：界面调整

> 2026-11-22，分支 `m4-ui`（从合并了 M4 第 1–4 项的 main 开出）。Mac：macOS 27.3，Xcode 27.0。设备：iPad Pro 11 英寸（2018），iPadOS 26.7.3。
> 界面在 iPad Pro 11 英寸（M5）模拟器（iOS 27.0）上用 1 万张合成库跑界面测试；真机上的步骤由用户做，没做的写 NOT RUN。

## 范围

M4 真机验收时用户提的（原话见[沟通记录](../沟通记录.md)第 12 轮）：

> 选择收藏夹点导出时，照片总量显示11126，显示错误，导出是正确的； 缩放操作时会进入选择照片模式，修改逻辑，长按进入选择照片；

> 界面交互和使用往ipad便利和舒适性上提升……由你从专业设计师角度来考虑，实施；

| 改了什么 | 原来 | 现在 | 为什么 |
| --- | --- | --- | --- |
| 导出范围的写法 | “名字 张数”：收藏夹“111”、26 张读成“11126 张” | “收藏夹「111」 · 26 张”“11月21日 周六 · 93 张”“全部照片的筛选结果 · 12 张” | 名字里有数字时和张数连在一起 |
| 进入选择 | 点“选择”；系统的两指拖选（捏合的头一下会被当成两指拖，一捏就进了选择） | **长按**一张进入选择，那张选上，按住接着拖是连选（往哪个方向都行，拖到上下边缘自动滚）；“选择”按钮还在；两指拖选关掉 | 用户要求；长按是 iPad“照片”的习惯 |
| 筛选条 | 网格上面一直占一条（★1+ … ★5+、Pick / Reject / 未标记） | 工具栏“筛选”按钮 + 弹出框；有条件时图标实心、带个数，副标题“筛选出 N / M 张”；弹出框里能连着点几个，底下有张数和“清除筛选” | 选片时大多不筛，一直占着一条浪费竖向空间、看着乱 |
| “刷新结果” | 在筛选条右边 | 浮在网格底部正中（玻璃胶囊） | 筛选条没了；底部手指够得着 |
| 右上角 | 7 个：撤销、重做、读卡、排序、导出、选择、设置 | 撤销、重做、筛选、“更多”（…）、选择 | 只留选片时常用的，合成一组 |
| 排序 | 单独一个按钮 | 进“更多” | 很少改 |
| 读卡 | 右上角按钮 | 设置最上面“存储卡”一节：状态 + “读取存储卡”（先关设置再读，选卡的选择器挂在主界面上）；没有照片时空白页上的按钮还在 | 插上卡就自动读，很少要点 |
| 设置 | 右上角 | 侧栏顶上（齿轮） | iPad 上全局的东西放侧栏 |
| 导出 | 右上角（导当前结果），选择模式也有 | ① 选了照片后底部操作条的“导出”；② 侧栏按住全部照片 / 一天 / 日期未知 / 收藏夹 →“导出…”（导这一项全部的，不管筛选）；③ “更多”→“导出这 N 张… / 导出筛选结果 N 张…” | 用户的建议；③ 留给“筛完直接导” |
| 选择模式的按钮 | 右上角一排：打星、标记、收藏夹、导出、撤销、重做；“完成”“全选”在左边 | 底部浮着操作条：打星、标记、收藏夹、导出（图标带字，44 点高）；右上角撤销、重做、“完成”；左上角“全选” | 手指够得着、看得懂；“完成”回到右上角是 iPad 惯例 |

没改：单张视图（下面一排星级、标记、收藏夹、自动前进，轻点照片整排藏起来）。

### 真机步骤

1. 网格里捏合放大缩小几次，看会不会进选择状态（不应该）。
2. 长按一张：进入选择、那张打勾；再长按一张按住往下拖，看连选。点“完成”。
3. 侧栏按住一个收藏夹 →“导出…”，看范围那一行（不用真导）。按住某一天也试一下。
4. 右上角“筛选”：点 ★3+、Pick，点外面关掉，看图标变实心、副标题“筛选出”。进单张视图改几张的星级，回来看底部“刷新结果”。
5. 设置（侧栏顶上的齿轮）→“读取存储卡”。
6. 用一会儿，告诉我哪里不顺手。
