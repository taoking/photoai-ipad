## 做了什么

| 功能 | 怎么做的 | 参考 Mac 版 |
| --- | --- | --- |
| F-16 单张换原图 | 单张视图在一张上停 0.3 秒、卡连着：按照片在屏幕上的长边像素（横拿 iPad、全屏时约 2,388）从卡上读 JPG / HEIF 换掉 1600 预览。屏幕上要的比预览大不到一成就不读（竖拿 iPad 看横图）。只有 ARW 的照片不读（iPad 解不了 RAW）。只留当前这张，翻走就放掉。转屏、隐藏工具条后照片变大了再看一次。上面一行文件名旁边写着“原图”或“预览” | 设计稿 §7.3 V-3 |
| | 读不到（卡拔了、文件没了）就留在预览，不提示、**不标“卡上已删”**：这是看照片时自动发生的，不悄悄改照片的状态。放大时读原图照旧会标 | 设计稿 §4.1 |
| F-17 直方图 | 上面一行的直方图按钮，照片右上角浮一块：红绿蓝叠加，白线是亮度；高光溢出、暗部死黑超过 0.5% 时下面写一行橙字。按 1600 预览算（缩到 320 再数）；停 0.12 秒才算。轻点照片藏起工具条时它也藏。开关记在本机设置里 | `Histogram.swift` 照搬；设计稿 §6.1 |
| F-18 对焦框 | 核心层 `FocusReading.swift`：导入时预览做完后读还没读的对焦框（只读文件头），存进库，卡拔了照样显示。上面一行对焦框按钮（开着时绿色）；开着时旁边多一个“放大到对焦点”（以框中心放大到 100%，再点回到适合屏幕；这张没框时灰掉）。框画在照片上、跟着缩放走，线不变粗；小框至少画 18 点见方。“i”里加了一行“对焦框：有 / 相机没记 / 还没读” | `FocusPoint.swift` 照搬、`FocusReading.swift` 改成一张卡；设计稿 §6.2 |
| 快捷键 | 单张视图：`A` 显示 / 隐藏对焦框、`⇧Z` 放大到对焦点（同 Mac 版）；`H` 显示 / 隐藏直方图（iPad 版加的） | Mac 版 `KeyCommands` |

和 Mac 版不一样、Claude 自己定的（没有问用户）：

- 直方图按 1600 预览算，不按 480 缩略图：两者都缩到 320 再数，1600 的细节多一点；单张视图手里本来就有它。
- 直方图浮在照片上（Mac 版在检查器里），默认关：iPad 屏幕小，不一直占着。
- 换原图只留当前这张（Mac 版留前后各一张）：翻回去再停 0.3 秒读一次，省内存、少写代码。
- 读对焦框排在预览做完之后：选片先要预览；对焦框每张约 1 ms（M0），2,000 多张几秒。
- 合成的性能测试库加了对焦框（每三张一张相机没记），界面测试用；已有的合成库要删掉重建才有。

## 结论

### 真机步骤

1. 装好后插卡，等读完（设置里“存储卡”看状态）。已经读过的卡也会再扫一遍，这次会顺带读对焦框。
2. 进单张视图，停在一张上：文件名旁边的“预览”过一下变成“原图”，画面更清楚。快速左右翻几张，再停下。
3. 点上面的对焦框按钮（变绿）：照片上出现绿框。多翻几张，对着照片看框是不是在你对焦的地方，尤其是人眼对焦、竖拍的照片。
4. 点旁边的放大镜（放大到对焦点），看框里清不清楚；再点一下回来。
5. 点直方图按钮，翻几张亮的、暗的。
6. 接着键盘的话试 `A`、`H`、`⇧Z`。
7. 拔掉卡再翻几张：应该一直是“预览”，不弹错误。
8. 用一会儿，告诉我哪里不顺手。我会拉日志看换原图、读对焦框的耗时和内存。
